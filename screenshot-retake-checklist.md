# Screenshot Re-take Checklist (Waveform 11 → current UI)

These 452 screenshots still show the **old Waveform 11 interface** and need re-capturing in the current UI. They were identified by image resolution (every up-to-date screenshot is a 144&nbsp;dpi Retina @2x capture; these are the remaining 72&nbsp;dpi originals).

**How to work through this list:**

1. Re-capture each shot on a **Retina display** so it is a 2x image.
2. Save it into `docs/images/` named with an **`@2x` suffix** — e.g. replace `12----01.png` with **`12----01@2x.png`** (keep the same base name, just add `@2x`).
3. Tell me when a chapter (or batch) is done and I will **re-point the references** from the old name to the new `@2x` name and remove the stale files — same as we did for the Audio FX / Instruments galleries.
4. Tick the box here as you go.

> The **Show** column is the existing manual caption for that image, so you know what each frame should contain.
